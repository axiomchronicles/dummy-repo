# ADR-003: explicit local demo and bounded private database artifacts

Accepted2026-10-24. Isolated development identities and hashed sessions support zero-cloud demo; production configuration rejects bypass. Upload/report limits allow private PostgreSQL bytea artifacts and authorized direct download. No object store/mail/auth cloud required for complete local slice. Five editable persona snapshots are data. Native CSS and persisted timelines fulfill operational requirements without optional graph/Tailwind libraries. Later production auth/large recording storage require explicit verified integration. Missing original/V2 documents are recorded, not reconstructed as fact.

Frontend implementation note: the native-CSS recommendation is superseded by the current explicit user request and ADR005. Actual frontend now uses Tailwind4 and shadcn neutral components with open layouts. Database artifact and demo-auth decisions still apply.
