# ADR-004: smallest verified Sarvam API and acknowledged webhook fallback

Accepted2026-10-24. Use instant outbound attempts, retaining local campaign ownership. Current official contract has no documented signature/idempotency/cancel. Live requires explicit configured bearer-route fallback and authorized destinations; no invented HMAC. Published official SDKs do not expose this outbound operation; ADR005 adds the actual model SDK for optional LIVE content/summary endpoints while the verified dial adapter uses REST. Optional language override omitted because API enum/pricing marketing differ on Sanskrit. Actual call duration/billed cost are unavailable at initiation, so budget is conservative reservation with explicit estimate semantics, not guaranteed invoice cap. Live validation remains optional and no real call is authorized by this task.
